Finite Element Method online.

sdsd
Система прочностного анализа плоских конструкций online с помощью МКЭ.

Краткое описание системы.
Слева расположен редактор (область 300х300).
Сверху кнопки управления.
Справа текстовое представление рисунка в формате JSON.

Инструкция:
1. Задать набор горизонтальных линий (HLine button). По окончании нажимаем кнопку "Cancel Enter".
2. Задать набор вертикальных линий (VLine button). По окончании нажимаем кнопку "Cancel Enter".
3. Задать набор прямоугольников (Rect button).
По окончании нажимаем кнопку "Cancel Enter".
4. Задать набор граничных условий (Bound button). Граничное условие задается для стороны прямоугольника.
Пока что поддерживается не более одного граничного условия для одного прямоугольника.
По окончании нажимаем кнопку "Cancel Enter".
5. Задать набор нагрузок (Load button).
Нагрузка задается для стороны прямоугольника, затем выбирается величина и направление.
По окончании нажимаем кнопку "Cancel Enter".
6. Нажать кнопку "Solve area".
7. Подождать.

PS: на сложных областях система глючит.
Но это не критично, для демонстрации на конференции годится, а затем
все равно модуль триангуляции придется переписывать, потому что без возможности задаваить более сложные области
система не представляет интереса.
